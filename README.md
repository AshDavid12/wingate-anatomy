# אנטומיה למבחן — Origin · Insertion · Action

כלי לימוד אינטראקטיבי למבחן אנטומיה של מדריכים ומאמנים (מכון וינגייט). הטבלאות בנויות סביב המושגים **Origin (התחלה)**, **Insertion (סיום)** ו־**Action (תפקיד תנועתי)** — כמו בחוברת של משה שחר.

> הקובץ המקורי (`חוברת אנטומיה של משה שחר 2023-4`) נשמר במחשב המקומי ולא היה זמין בסביבת הפיתוח. האפליקציה היא חומר לימוד מקורי לפי אנטומיה סטנדרטית, מסודר לפי נושאי הקורס (חגורת כתף, כתף, מרפק, בטן, גב, ירך, ברך, קרסול ומפרקים נבחרים). זה אינו העתק של החוברת.

## מה יש כאן

- **שרירים** — טבלה מלאה: שם (עברית + אנגלית), Origin, Insertion, Action, עצבוב. סינון לפי אזור, חיפוש, והסתרת עמודות לתרגול.
- **עצמות** — לכל עצם: שרירים שמתחילים עליה, שרירים שנאחזים בה, ותנועות המפרקים.
- **מפרקים** — כתף, שכמה–חזה, SC, AC, מרפק, שורש כף היד, ירך, ברך, קרסול.
- **כרטיסיות** — חזרה על Origin / Insertion / Action.
- **חידון** — שאלות רב-ברירה בסגנון מבחן.
- **מושגים** — מונחי תנועה וכיוונים אנטומיים.

## הרצה מקומית

```bash
npm install
npm run dev
```

ברירת המחדל: [http://localhost:4317](http://localhost:4317)

בנייה לייצור:

```bash
npm run build
npm start
```

## איך ללמוד

1. עברו על טבלת השרירים לפי אזור (כתף, ירך, שוק…).
2. סמנו «הסתר Origin / Insertion / Action» ונסו להשלים בעל-פה.
3. בטבלת העצמות בדקו איזה שריר מתחיל או נאחז בכל עצם — זה מה שהמבחן אוהב.
4. סיימו עם כרטיסיות וחידון.

שרירים מסומנים **הרחבה** הם מעבר לליבת החוברת המקוצרת; כדאי לדעת אותם אם המרצה הרחיב.
