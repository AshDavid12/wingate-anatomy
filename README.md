# אנטומיה למבחן — Origin · Insertion · Action

כלי לימוד אינטראקטיבי למבחן אנטומיה של מדריכים ומאמנים (מכון וינגייט). הטבלאות בנויות סביב המושגים **Origin (התחלה)**, **Insertion (סיום)** ו־**Action (תפקיד תנועתי)** — כמו בחוברת של משה שחר.

> הקובץ המקורי (`חוברת אנטומיה של משה שחר 2023-4`) נשמר במחשב המקומי ולא היה זמין בסביבת הפיתוח. האפליקציה היא חומר לימוד מקורי לפי אנטומיה סטנדרטית, מסודר לפי נושאי הקורס (חגורת כתף, כתף, מרפק, בטן, גב, ירך, ברך, קרסול ומפרקים נבחרים). זה אינו העתק של החוברת.

## מה יש כאן

- **שרירים** — טבלה: Origin, Insertion, Action, מישור, ומפרק. לחיצה פותחת איור ושרירים קשורים.
- **עצמות / מפרקים** — אחיזות שרירים, תנועות ומישורים.
- **מישורים** — Sagittal / Frontal / Horizontal: איזו תנועה על איזה מישור, עם תרגול הסתרה.
- **הצלבה** — אותה תנועה במפרקים שונים, שרירים דומים, אנטגוניסטים, Origin/Insertion לפי עצם.
- **מילון** — 132 מונחי שלד ושריר (רקמות, עצם, סחוס, מפרקים, רצועות, גידים, מבנה שריר) עם הסתרת הגדרות לתרגול.
- **אטלס / כרטיסיות / חידון** — כולל כרטיסיות מילון ושאלות מישור, קבוצות (SITS, quads, hamstrings) והגדרות.

## איך ללמוד

1. עברו על טבלת השרירים לפי אזור (כתף, ירך, שוק…).
2. סמנו «הסתר Origin / Insertion / Action» ונסו להשלים בעל-פה.
3. בטבלת העצמות בדקו איזה שריר מתחיל או נאחז בכל עצם — זה מה שהמבחן אוהב.
4. במילון עברו על מונחי רקמה, עצם, סחוס ומבנה שריר — סמנו «הסתר הגדרות».
5. סיימו עם כרטיסיות (שרירים או מילון) וחידון.

## איורים

האפליקציה כוללת אטלס תמונות לשרירים, עצמות ומפרקים (לוחות Gray's Anatomy, BodyParts3D ועוד מתוך ויקיפדיה / ויקישיתוף). לחצו על איור כדי להגדיל אותו. בחידון יש גם שאלות «איזה שריר באיור?».
