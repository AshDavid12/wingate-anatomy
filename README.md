# אנטומיה למבחן — Origin · Insertion · Action

כלי לימוד אינטראקטיבי למבחן אנטומיה של מדריכים ומאמנים (מכון וינגייט). הטבלאות בנויות סביב המושגים **Origin (התחלה)**, **Insertion (סיום)** ו־**Action (תפקיד תנועתי)** — כמו בחוברת של משה שחר.

> הקובץ המקורי (`חוברת אנטומיה של משה שחר 2023-4`) נשמר במחשב המקומי ולא היה זמין בסביבת הפיתוח. האפליקציה היא חומר לימוד מקורי לפי אנטומיה סטנדרטית, מסודר לפי נושאי הקורס (חגורת כתף, כתף, מרפק, בטן, גב, ירך, ברך, קרסול ומפרקים נבחרים). זה אינו העתק של החוברת.

## מה יש כאן

- **שרירים** — טבלה: Origin, Insertion, Action, מישור, ומפרק. לחיצה פותחת איור, «למה זה זז», קיצורי שינון (SITS, PFPF, SGT…), ושרירים קשורים.
- **היגיון** — חמש כללים להסיק תנועה מהמיקום (לא לשנן): משיכה בלבד, מפרק שהוא חוצה, צד=משפחה, תא=עבודה, והשם הלטיני.
- **שינון** — ראשים וחלקים (דלתואיד, ביצפס, תלת-ראשי…) לפי Origin ותנועה, טבלאות תנועה (עיקריים מול משנה, כמו בחוברת), קיצורי Origin/Insertion לפי נקודת אחיזה, ורשימת השרירים הדו-מפרקיים לפי זוג מפרקים.
- **עצמות / מפרקים** — אחיזות שרירים, תנועות ומישורים.
- **חלקי עצם** — כל ה-landmarks מהמצגות (שכמה, זרוע, אגן, חוליות…) עם איור, שם, מיקום ומבט. הסתרת שמות לתרגול זיהוי למבחן.
- **מישורים** — Sagittal / Frontal / Horizontal: איזו תנועה על איזה מישור, עם תרגול הסתרה.
- **הצלבה** — אותה תנועה במפרקים שונים, שרירים דומים, אנטגוניסטים, Origin/Insertion לפי עצם.
- **מילון** — מונחי שלד ושריר (רקמות, עצם, סחוס, מפרקים, רצועות, גידים, מבנה שריר) וגם מונחי גף תחתון מהמצגת.
- **אטלס / כרטיסיות / חידון** — כולל כרטיסיות מילון, קיצורי Origin/Insertion, ושאלות מישור, קבוצות (SITS, quads, hamstrings) והגדרות.

## איך ללמוד

1. התחילו ב«היגיון»: חמש הכללים + כרטיס הצד (הברך הפוכה). אחר כך מפת התא של האזור.
2. עברו על טבלת השרירים לפי אזור. מעל הטבלה תופיע מפת התא — קדמי/אחורי/מדיאלי.
3. בלשונית «שינון» פתחו «ראשים וחלקים» לדלתואיד / ביצפס / תלת-ראשי, אחר כך תנועות לפי קבוצה, קיצורי Origin/Insertion, ורשימת הדו-מפרקיים. סמנו «הסתר» ונסו להשלים בעל-פה.
4. בטבלת השרירים סמנו «הסתר Origin / Insertion / Action» ונסו להשלים בעל-פה.
5. ב«חלקי עצם» עברו עצם-עצם, סמנו «הסתר שמות» ונסו לזהות את החלק באיור.
6. בטבלת העצמות בדקו איזה שריר מתחיל או נאחז בכל עצם — זה מה שהמבחן אוהב.
7. במילון עברו על מונחי רקמה, עצם, סחוס ומבנה שריר — סמנו «הסתר הגדרות».
8. סיימו עם כרטיסיות וחידון (כולל שאלות קיצורי שינון).

## איורים

האפליקציה כוללת אטלס תמונות לשרירים, עצמות ומפרקים: איורי מצגת הגף התחתון (ירך, ברך, קרסול) לצד לוחות Gray's Anatomy / BodyParts3D מוויקיפדיה וויקישיתוף. לחצו על איור כדי להגדיל ולראות את כל תמונות המצגת. בחידון יש גם שאלות «איזה שריר באיור?».
